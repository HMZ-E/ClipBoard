# ClipBoard

## Overview
ClipBoard is a native macOS utility application designed to seamlessly capture, preserve, and manage clipboard history. Built specifically for the macOS desktop environment, it operates efficiently in the background to ensure users never lose access to previously copied text or data, enhancing daily productivity and workflow efficiency.

## Key Features
* Background Monitoring: Silently captures clipboard events without interrupting the user workflow.
* Historical Retention: Stores a chronologically ordered list of previously copied items for instant retrieval.
* Native Integration: Designed to feel like a built-in macOS utility with a clean, unobtrusive interface.
* Optimized Performance: Maintains a lightweight processing footprint to minimize memory and CPU utilization.

## Technical Stack
* Platform: macOS
* Framework: SwiftUI / AppKit
* IDE: Xcode
* Language: Swift

## Installation and Setup
1. Clone the repository to your local machine.
2. Open the `ClipBoard.xcodeproj` file in Xcode.
3. Wait for Xcode to resolve any Swift Package Manager dependencies.
4. Select your target Mac and build the application.
